# Documentation map

Current documentation lives directly under `docs/` unless a document explicitly says otherwise.

Start with:
- `ARCHITECTURE.md` — implementation architecture.
- `CONFORMANCE.md` — semantic verification model.
- `DATA_PROVENANCE.md` — generated-data provenance.
- `PUBLIC_API_ARCHITECTURE.md` — hosted public API contract.
- deployment, release, supply-chain, localization, and rolling-cache documents beside them.

Completed stages, superseded benchmark narratives, frozen provenance artifacts, and release evidence live under `docs/history/`. They are evidence, not current operating instructions.

Non-production experiments and benchmark variants live under `../research/`.
