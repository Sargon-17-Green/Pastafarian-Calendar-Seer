# Terminology

## Scroll

The normative specification of the Pastafarian Calendar. The Scroll defines the answer.

## Monster

The historical/liturgical implementation lineage that performs the prescribed work and
preserves the accumulated spaghetti history.

## Seer

The accelerated engine in this repository. The Seer is **not permitted by the Monster**
to bypass the liturgy; it does so anyway. Technically it may use any exact shortcut
chosen by the maintainers of this repository, provided the normative result is preserved.
It is not a normative authority.

## Oracle

Use `oracle` in this project primarily in the software-testing sense: an independent
reference used to decide whether a result is correct.

This distinction is intentional. Calling the accelerated engine “Oracle” would make it
too easy to confuse the fast implementation with the source of truth. The Seer predicts;
the normative oracle checks.
