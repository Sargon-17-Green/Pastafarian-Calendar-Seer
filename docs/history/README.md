# Historical evidence

Everything below this directory is historical evidence unless a file explicitly states otherwise. Moving a file here does not invalidate it and does not rewrite its claims.

- `benchmarks/` — completed A/B experiments and their checksum ledgers.
- `stages/` — completed implementation-stage documents.
- `releases/` — dated QA/release evidence.
- `provenance/` — frozen provenance/checksum artifacts.
- `root-artifacts/` — historical root-level delta/package artifacts.
- `prototype/` — frozen documentation/checksum snapshot of the original benchmark prototype.

Embedded paths and hashes in frozen artifacts intentionally describe the historical layout in which they were produced.
